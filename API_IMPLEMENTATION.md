# 📡 API Реализация для TB Group Website

## Архитектура

### Текущая реализация

Сайт на Vercel включает встроенный serverless API для обработки форм обратной связи:

```
Frontend (Vercel)          →   Serverless API (Vercel)   →   Bitrix24
┌─────────────────────┐           ┌──────────────────┐         ┌──────────────┐
│  Contact Form       │   HTTP    │  /api/contact    │   REST  │  Lead Create │
│  - Multi-step form  │─────────→ │  - Validate      │─────────→│  - CRM Lead  │
│  - Validation       │           │  - Process       │         │  - History   │
│  - Submit           │           │  - Send to B24   │         │              │
└─────────────────────┘           └──────────────────┘         └──────────────┘
```

## API Endpoint

### POST /api/contact

Создание лида в Битрикс24 через веб-сайт.

#### Запрос

```json
{
  "fullName": "Иван Петров",
  "email": "ivan@example.com",
  "phone": "+77771234567",
  "company": "ТОО «Компания»",
  "message": "Хочу внедрить Мой Склад",
  "serviceInterest": "Мой Склад"
}
```

#### Ответ (успех)

```json
{
  "status": "success",
  "contactRequestId": "web-1731254155000",
  "leadId": "12345",
  "message": "Заявка успешно отправлена!"
}
```

#### Ответ (ошибка)

```json
{
  "error": "Необходимо заполнить все обязательные поля"
}
```

#### Статусы ответа

- `200` - Успех
- `400` - Ошибка валидации
- `500` - Ошибка сервера

## Интеграция с Битрикс24

### Вебхук
URL: `https://tbgroup.bitrix24.kz/rest/18/kjdwaeorinhxto5q/`

### Поля лида

| Поле Bitrix24 | Источник | Обязательно |
|--------------|----------|-------------|
| TITLE | Заголовок | Да |
| NAME | Имя клиента | Да |
| EMAIL | Email | Да |
| PHONE | Телефон | Да |
| COMPANY_TITLE | Компания | Нет |
| COMMENTS | Сообщение + метаданные | Нет |
| SOURCE_ID | Источник (WEB) | Да |
| STATUS_ID | Статус (NEW) | Да |
| CURRENCY_ID | Валюта (KZT) | Да |

### Логирование

Все запросы логируются в консоль Vercel:
```javascript
console.log('Lead created in Bitrix24:', data.result);
```

## Локальная разработка

### Без API (Frontend Only)

```bash
npm run dev
```
Форма покажет предупреждение о reCAPTCHA, но отправится на Vercel API.

### С внешним API

Установите переменную окружения:
```bash
NEXT_PUBLIC_API_BASE_URL=http://localhost:4000
```

Запустите API сервер:
```bash
cd apps/api
npm run dev
```

## Устранение неисправностей

### CORS ошибки
- ✅ Исправлено: используем same-origin API на Vercel
- Нет CORS, так как фронтенд и бэкенд на одном домене

### Ошибка 500
Проверьте логи в Vercel Dashboard:
1. Deployments → Your Deployment → Functions → /api/contact

### Лид не создается в Битрикс24
1. Проверьте вебхук URL
2. Проверьте права доступа к CRM в Битрикс24
3. Проверьте обязательные поля

### Форма не отправляется
1. Проверьте консоль браузера
2. Проверьте Network tab
3. Проверьте обязательные поля

## Производительность

- **Serverless функция** запускается при первом запросе
- **Холодный старт**: ~100-200ms
- **Теплый старт**: ~50ms
- **Timeout**: 30 секунд
- **Размер бандла**: 87.3 kB (общий)
