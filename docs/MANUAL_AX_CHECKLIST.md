## 9. Автоматизированное Тестирование (Axe-core)

### Интеграция в Разработку

В файл `apps/web/src/app/layout.tsx` интегрирована загрузка axe-core в development режиме:

```typescript
{process.env.NODE_ENV === 'development' && (
  <Script id="axe-config" strategy="afterInteractive">
    {`
      // Load axe-core for accessibility testing in development
      (function() {
        if (typeof window !== 'undefined' && !window.axe) {
          var script = document.createElement('script');
          script.src = 'https://cdnjs.cloudflare.com/ajax/libs/axe-core/4.11.0/axe.min.js';
          script.onload = function() {
            console.log('🔍 Axe-core loaded for accessibility testing');
          };
          document.head.appendChild(script);
        }
      })();
    `}
  </Script>
)}
```

**Статус**: ✅ ИНТЕГРИРОВАНО

### Запуск Axe-core в DevTools

1. Открыть сайт в Chrome DevTools
2. В консоли выполнить: `axe.run()`
3. Проверить результаты в консоли

**Примечание**: Axe-core запускается автоматически в development и может быть вызван вручную для анализа.
