# Динамические OG Изображения — Документация

## Обзор

Реализована система динамических Open Graph изображений для улучшения SEO и привлекательности при шеринге страниц в социальных сетях.

## Технические Детали

### API Маршрут
- **Путь**: `/api/og`
- **Runtime**: Edge (для быстрой генерации)
- **Размер изображения**: 1200x630 пикселей (стандарт для OG изображений)

### Поддерживаемые Параметры

| Параметр | Тип | Обязательный | Значение по умолчанию | Описание |
|----------|-----|--------------|----------------------|----------|
| `title` | string | Нет | "TB Group" | Заголовок изображения |
| `description` | string | Нет | "Облачные решения для бизнеса" | Описание под заголовком |
| `type` | string | Нет | "default" | Тип шаблона (default, service, case) |

### Шаблоны

#### 1. Default (Главная страница)
- **Цвет**: Синий градиент (#0f172a → #1e293b)
- **Бейдж**: TB Group
- **Цвета декорации**: Синий (#3b82f6)

#### 2. Service (Страницы услуг)
- **Цвет**: Зеленый акцент (#10b981)
- **Бейдж**: ⚙️ Услуга
- **Цвета декорации**: Зеленый (#10b981)

#### 3. Case (Кейсы)
- **Цвет**: Оранжевый акцент (#f59e0b)
- **Бейдж**: 📊 Кейс
- **Цвета декорации**: Оранжевый (#f59e0b)

## Использование

### Базовый URL
```
/api/og
```

### Примеры

**Главная страница:**
```bash
/api/og?type=default&title=TB Group — Облачные решения для бизнеса&description=Внедрение Мой Склад, Битрикс24 и корпоративной телефонии
```

**Страница услуги:**
```bash
/api/og?type=service&title=Мой Склад&description=Внедрение системы Мой Склад
```

**Страница кейса:**
```bash
/api/og?type=case&title=Кейс: Автоматизация ритейла&description=Реальные результаты внедрения
```

### URL Encoding

При использовании кириллических символов необходимо кодировать параметры:

```javascript
const title = encodeURIComponent('Мой Склад');
const description = encodeURIComponent('Внедрение системы');
const url = `/api/og?type=service&title=${title}&description=${description}`;
```

## Интеграция с Метаданными

### Настройка в Next.js

Все страницы сайта настроены на использование динамических OG изображений:

```typescript
// pages/(site)/page.tsx
export const metadata = {
  openGraph: {
    title: 'TB Group — Облачные решения для бизнеса',
    description: 'Внедрение Мой Склад, Битрикс24 и корпоративной телефонии',
    images: [
      {
        url: '/api/og?type=default&title=TB Group — Облачные решения для бизнеса&description=Внедрение Мой Склад, Битрикс24 и корпоративной телефонии',
        width: 1200,
        height: 630,
        alt: 'TB Group — Облачные решения для бизнеса',
      },
    ],
  },
};
```

### Обновленные Страницы

1. **Главная страница** (`/`)
   - Тип: `default`
   - Использует метаданные из `apps/web/src/app/(site)/page.tsx`

2. **Услуги** (`/services`)
   - Тип: `service`
   - Использует метаданные из `apps/web/src/app/(site)/services/page.tsx`

3. **Кейсы** (`/cases`)
   - Тип: `case`
   - Использует метаданные из `apps/web/src/app/(site)/cases/page.tsx`

4. **О компании** (`/about`)
   - Тип: `default`
   - Использует метаданные из `apps/web/src/app/(site)/about/page.tsx`

5. **Контакты** (`/contact`)
   - Тип: `default`
   - Использует метаданные из `apps/web/src/app/(site)/contact/page.tsx`

6. **Динамические страницы услуг** (`/services/[slug]`)
   - Тип: `service`
   - Генерирует OG изображение на основе данных услуги
   - Использует `encodeURIComponent()` для правильного кодирования

## Устранение Неполадок

### Проблема: Изображение не загружается
**Решение**: Проверить URL encoding параметров, особенно для кириллических символов

### Проблема: Неправильные размеры
**Решение**: Убедиться, что width=1200 и height=630 указаны в metadata

### Проблема: Медленная загрузка
**Решение**: Настроить CDN кэширование или перенести на более быстрый Edge регион
