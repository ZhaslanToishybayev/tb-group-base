# 🔓 Руководство по доступу к тестированию продакшн

## Проблема
Все деплои Vercel защищены аутентификацией (ошибка 401).

## Решения (Выберите одно)

### Вариант 1: Отключить защиту в панели управления Vercel (Рекомендуется)

1. Перейти в [Панель управления Vercel](https://vercel.com/dashboard)
2. Выбрать проект: `tb-group-base-current-changes-backup`
3. Перейти в **Настройки** → **Функции**
4. Найти **"Deployment Protection"**
5. Выключить его **OFF**
6. Передеплоить или подождать 5 минут для применения изменений
7. Тестировать: https://tb-group-base-current-changes-backup-1kw5t57qb.vercel.app

### Вариант 2: Использовать Vercel CLI с Bypass токеном

1. Установить Vercel MCP (если еще не установлен):
   ```bash
   npm i -g @vercel/mcp
   ```

2. Получить bypass токен из панели управления Vercel:
   - Настройки проекта → Функции → Protection Bypass

3. Доступ с токеном:
   ```
   https://tb-group-base-current-changes-backup-1kw5t57qb.vercel.app?x-vercel-set-bypass-cookie=true&x-vercel-protection-bypass=ВАШ_ТОКЕН
   ```

### Вариант 3: Локальное тестирование (Уже работает)

1. Локальный сервер запущен по адресу: http://localhost:3000
2. Все функции можно тестировать локально
3. Формы будут работать (API маршруты активны)
4. Примечание: Некоторые внешние интеграции (GA4, Bitrix24) требуют продакшн среду
